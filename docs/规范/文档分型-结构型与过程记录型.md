# 文档分型 —— **结构型** 与 **过程记录型**

> **作者 2026-10-10 原话**：
> 「**更新文档，必须分清，是过程记录型文档 还是结构型文档，不要什么过程记录，都往结构型文档中放。**」

---

## 一 · 两类各答什么

| 类 | 答的问题 | 读者什么时候看 |
|---|---|---|
| **结构型** | 「**现在是什么样**」 | 要**动手** / 要**判断现状**的时候 |
| **过程记录型** | 「**当时发生了什么 · 为什么这么定**」 | 要**追责 / 追因 / 避免重犯**的时候 |

**两类都要有，⛔ 不是"过程记录没价值"** —— 是**它们不能混在一份文件里**。
🔴 **混了之后，读的人【分不出哪句是现状、哪句是历史】** —— 而**那份文件恰恰是给"只想看现状"的人读的**。

---

## 二 · 判据（**一句话**）

> **写下一句话之前，问：这句话在说「现在」，还是在说「过去」？**
> · **现在** ⇒ 结构型文档
> · **过去** ⇒ 过程记录型文档
> · **过去解释了现在** ⇒ **结论写结构型 + 指针指过程记录**（⛔ 不是把过程抄进结构型）

---

## 三 · 哪些是结构型

| 文档 | 答什么 |
|---|---|
| `README.md` | 这东西是什么 · 怎么跑 |
| `CLAUDE.md`（根 + 各层） | 这里的规矩 · 有什么 · 去哪找 |
| `docs/原理/架构.md` | 模块怎么连 · 请求怎么走 |
| `docs/契约/` | 接口 / 环境变量 / 表结构（**对外承诺**） |
| `docs/规范/` | 规矩本身 |
| `app/<组>/specs/<模块>.md` | **这个模块现在做到哪 · 看代码会误判什么** |
| `app/` 下【各组的 `CLAUDE.md`】·  等 | 各层索引与门一览 |
| `docs/说明/` | 怎么部署 / 运维 / 测（**操作说明**） |

## 四 · 哪些是过程记录型

| 文档 | 记什么 |
|---|---|
| `CHANGELOG.md` | **改动本身**（用户能感知的变化） |

## 五 · ⛔ 结构型文档里【不许】出现的句式

| ⛔ 不许 | 为什么 |
|---|---|
| 「**原文写 X ⇒ 更正为 Y**」（成块的） | 那是**变更记录** ⇒ 归 `CHANGELOG` |
| 「**2026-0X-XX 我踩了……**」「**当时我判断错了**」 | 那是**复盘** ⇒ 归  |
| 「**改前是 A，改后是 B**」的**逐条沿革** | 那是**改动史** ⇒ 归 `CHANGELOG` / `DEC` |
| 「**这条待裁 / 要不要做 X**」 | 那是**待办** ⇒ 归  |

## 六 · ✅ 结构型文档里【该】有的

| ✅ 该有 | 例 |
|---|---|
| **结论**（现在是什么） | 「`alembic` 已装、已进 `app/requirements.txt`（`==1.20.0`）」 |
| **判据（一条能跑的命令）** | `venv/bin/alembic --version` ⇒ `alembic 1.20.0` |
| **指针**（要读经过 ⇒ 去哪） | 「📄 为什么改 ⇒ `DEC-XXX`」 |
| **限制 / 坑**（⛔ 不是"当时的坑"，是"**现在仍然成立**的坑"） | 「⛔ 别对真库跑 `upgrade head`」 |

---

## 七 · ⚠️ 一条【边界】：`specs/` 的「✅ 做了什么」

本仓 spec 模板的第二段就叫 `## ✅ 做了什么`，**它天然带日期**（"2026-10-03 改了 X"）。
⚠️ **它不是违规** —— 但**判据要收紧**：

> **那条沿革【改变了"看代码会误判什么"】就留；纯过程就删。**
> · ✅ **留**：「改前判据是 `hasattr(response, "usage")`，**恒为 False**」——
>   读的人**现在**看代码仍会误判（属性名是 `usage_metadata`）⇒ 这是**结构信息**
> · ⛔ **删**：「当时我先写成 A，后来发现 B 更合适」—— 对"现在"零信息

📌 **一句话**：**spec 记的是「这个模块现在是什么样、哪里会看错」，⛔ 不是"这个模块的历史"。**

## 八 · 判据（可打印）

```bash
# 结构型文档里不该出现成块的「原文写…更正为…」（⛔ 排除过程记录型文档自己）
grep -rn "原文写\|更正为" README.md CLAUDE.md  docs/原理/*.md 2>/dev/null | head

# 结构型文档里不该有「待裁 / 要不要做」（那是待办的事）
grep -rn "待裁\|要不要" README.md CLAUDE.md  2>/dev/null | head
```

> ⚠️ **这两条 grep 是【提醒】不是门** —— 「算不算成块」「算不算纯过程」是**判断**，机械判不了。
> 📌 但**同一个量级的错**本仓栽过多次（`README` 里「三种模式」「真中断」留了好几天没人发现）
> ⇒ 它的价值是**让下一个人看得到**，⛔ 不是"跑绿了就没问题"。
