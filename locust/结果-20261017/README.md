## 一 · 怎么复算（别靠读表）

```bash
cd locust/结果-20261017
python3 - <<'PY'
import csv, glob
for f in sorted(glob.glob("*_stats.csv")):
    for r in csv.DictReader(open(f)):
        if r["Name"] == "Aggregated":
            print(f"{f:<45} req={r['Request Count']:>5} fail={r['Failure Count']:>5} "
                  f"p50={r['50%']:>5} p95={r['95%']:>5} p99={r['99%']:>6}")
PY
```

### 2.3 付费档 · `POST /rag/search`（3 把 key · 9 并发）—— 下表是**该端点自己**那一行

| 目录里的名字 | 配置 | 时长 | 样本 | 失败率 | avg | p50 / p95 / p99 (ms) |
|---|---|---|---:|---:|---:|---|
| `paid-u3-60s-FIXED-QUESTION-cache-trap` | 固定一句话（**反面教材**） | 60 s | 10 | 0 % | 486 | 30 / 3800 / 3800 |
| `paid-u9-60s-question-pool` | 18 句问题池 | 60 s | 23 | 0 % | 999 | 1100 / 3300 / 3400 |
| **`paid-fast-u9-5min`** | **`fast`（不改写）** | 5 min | **211** | 0 % | 68 | **27 / 350 / 450** |
| **`paid-acc-u9-5min`** | `accurate_norerank`（**缓存命中为主**） | 5 min | **205** | 0 % | 143 | **27 / 98 / 3300** |
| **`paid-acc-u9-3min-FORCED-MISS`** | `accurate_norerank`（**强制 miss = 冷路径**） | 3 min | **63** | 0 % | **3680** | **3400 / 6800 / 7900** |

⚠️ **这三行别混着读**：
· `fast` = **没有改写**（也没有那把云 API 调用）；
· `acc-5min` = **有改写，但问题池只有 18 句、跑 205 次 ⇒ 约 89 % 命中缓存** ⇒ 27 ms **是缓存命中**；
· `acc-FORCED-MISS` = **每次换一句 ⇒ 必然 miss** ⇒ **这才是"改写到底多贵"**。

⚠️ **`paid-u3-60s-FIXED-QUESTION-cache-trap` 留着是有意的**：它是"**固定一句话压检索 = 压缓存**"
那条教训的原始证据（p95/p99 3800 ms 是冷启动那几次，p50 30 ms 全是命中）。
