这一页怎么读

  • 分组按资源（认证 / 入库 / 检索 / …），⛔ 不是按 HTTP 方法。
  • 身份那一行写的是这条接口要什么；「豁免」= 它在中间件豁免名单里，⛔ 不等于"公开"。
  • ⚠️ 参数表里的「说明」一栏全是「—」：本仓接口没有逐字段写说明，⛔ 我不替它们编。
  • 🔴 当下这批的统计：65 条端点里，30 条声明了返回形状（下面每条的「响应」格摊开它的真结构）；剩下 35 条还没声明。
  • 🔴 响应示例分两种：声明了返回形状的摊开真结构（字段名 + 类型）；没声明的那一格如实说「这条还没声明」—— ⛔ 不手写一个像样的样例（那是编的）。
